# Écureuil 🐿️

_Écureuil_ (nom de code) est une petite liste de courses, hors ligne d'abord, pour un foyer : un catalogue des items qu'on rachète sans cesse, chacun avec son rayon dans chacun de nos magasins, pour que la liste se lise dans l'ordre où l'on parcourt le magasin. Une personne possède la liste ; l'autre peut proposer des items, qui arrivent dans une section « À valider ». Elle tourne en PWA sur le téléphone (et sur le Mac pour la configuration), se synchronise par un journal d'événements append-only, et se veut d'abord ludique et accessible.

Voir [`CLAUDE.md`](CLAUDE.md) pour les commandes et l'organisation du dépôt, [`GLOSSARY.md`](GLOSSARY.md) pour le vocabulaire du domaine et [`docs/adr`](docs/adr) pour les décisions derrière la conception.
