# Écureuil 🐿️

_Écureuil_ (codename) is a small, offline-first grocery list for one household: a catalogue of the items we keep buying, each filed under the aisle where it sits in each of our stores, so the list reads in the order we walk the store. One person owns the list; the other can suggest items that land in a "to validate" section. It runs as a PWA on the phone (and the Mac for configuration), syncs through an append-only event journal, and is built to be whimsical and accessible first.

See [`CLAUDE.md`](CLAUDE.md) for commands and layout, [`GLOSSARY.md`](GLOSSARY.md) for the domain vocabulary and [`docs/adr`](docs/adr) for the decisions behind the design.
